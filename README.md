# Исследование алгоритма HyperLogLog

## Описание

Реализация и исследование вероятностного алгоритма HyperLogLog для оценки количества уникальных элементов в потоке данных. Включает стандартную и улучшенную версию алгоритма, а также инфраструктуру для генерации потоков и хеш-функций.

## Структура проекта

```
├── include/              # Заголовочные файлы
│   ├── random_stream_gen.h
│   ├── hash_func_gen.h
│   ├── hyperloglog.h
│   ├── hyperloglog_improved.h
│   └── exact_counter.h
├── src/                  # Исходные коды
│   ├── main.cpp
│   ├── random_stream_gen.cpp
│   ├── hash_func_gen.cpp
│   ├── hyperloglog.cpp
│   ├── hyperloglog_improved.cpp
│   └── exact_counter.cpp
├── scripts/
│   └── plot.py           # Скрипт для построения графиков
├── data/                 # CSV-данные (генерируются при запуске)
├── plots/                # Графики (генерируются plot.py)
├── report.md             # Отчет по исследованию
└── CMakeLists.txt
```

## Сборка и запуск

```bash
mkdir build && cd build
cmake ..
make
./main
cd ..
python3 scripts/plot.py
```

## Этапы

1. **Инфраструктура**: `RandomStreamGen` (генерация потоков строк), `HashFuncGen` (полиномиальный хеш с финализацией)
2. **Стандартный HyperLogLog**: реализация с коррекциями для малых и больших значений
3. **Анализ**: сравнение с теоретическими границами ошибки
4. **Улучшенная версия**: компактное хранение регистров (6 бит вместо 8), взвешенная коррекция малых значений

## Зависимости

- C++17
- CMake >= 3.14
- Python 3 + matplotlib + pandas (для графиков)
